# AGENTS.md — how to author content packs

This repository holds **base content packs** for Agent-Aware
Terminal: mini games, quizzes and cards shown to the developer
while a coding agent works. The main app mounts this repo as the
`games-base/` git submodule; user- and agent-generated packs can
additionally be dropped into
`~/.local/share/agent-aware-terminal/content/` at runtime.

## The one rule

**Games are data, never code.** A pack is one JSON file rendered
by the app's content engine. Nothing here is executed, so a pack
can be generated by any agent, reviewed as text, and hot-loaded
mid-session. If you think you need code, you need a new *scene
type* in the engine — propose it in the main repo instead.

## Read this first (canonical sources)

If this file and the code disagree, **the code wins**:

1. `backend/app/content_engine.py` in the main repo
   ([FastAnt/meta_hack](https://github.com/FastAnt/meta_hack),
   `agent-aware-terminal/`) — the loader and validator. The pack
   schema lives in its module docstring; the hard rules are
   `validate_pack()` and `scene_targets()`.
2. The three packs in this repo are working examples of the
   three scene types.

## Pack anatomy

```json
{
  "id": "physics-orbits-001",
  "kind": "quiz",
  "kicker": "MINI GAME",
  "topic": "Physics",
  "title": "Click the orbit where Mercury should be",
  "hint": "Choose the innermost orbit",
  "scene": {"type": "orbits", "rings": 4,
            "dots": [{"ring": 2, "angle": 35}]},
  "body": "Optional paragraph under the scene.",
  "question": "Three planets are already placed. Which orbit is Mercury's?",
  "choices": [{"id": "venus", "label": "Venus"}],
  "answer": "ring-1",
  "explanation": "Mercury is the closest planet to the Sun…"
}
```

- `kind`: `quiz` (scored, needs `answer` + `explanation`) or
  `card` (news / refactoring suggestion: `title` + `body`, no
  answer, never scored).
- `answer` must be a choice `id` **or** a scene target:
  orbits → `ring-1..ring-N` (1 = innermost), diagram → node ids,
  network → no targets (use choices).
- Scenes:
  - `orbits`: `rings` 2–6; `dots` are decorative planets
    (`ring`, `angle` in degrees). For "find the missing planet"
    games, put dots on every ring *except* the answer.
  - `diagram`: `nodes` with 0..1 `x`/`y` (center) and `w`/`h`
    fractions, `edges` between node ids (drawn with arrows).
  - `network`: `layers` like `[3, 4, 2]`, fully connected,
    decorative — pair with formula/fact choices.
- File name = `<topic>-<slug>-<nnn>.json`, and `id` must equal
  the file stem. Topics: `physics`, `geometry`, `math`,
  `programming`, `architecture`, `ml`, `news`, `refactor`.

## Style guide

The app is a quiet, monochrome, grotesk instrument (Linear-like).
Packs must feel native:

- **Monochrome only.** No colors, no gradients, no emoji in
  titles/questions (a single functional glyph is fine).
- **Grotesk voice.** Plain, confident, short. Title ≤ 60 chars,
  question one sentence, 2–4 choices, explanation 1–2 sentences.
- **Facts must be true.** Difficulty from insight, not trivia
  traps; the explanation teaches the point after answering.
- **One idea per pack.** A pack is a 20-second moment, not a
  lecture. Cards: one suggestion with a concrete first step.
- English text (the app's UI language).

## Validate before you commit

From the main repo checkout:

```bash
cd agent-aware-terminal
python3 -c "
from backend.app.content_engine import scan_packs
packs, errors = scan_packs(['games-base', 'content/games'])
print(len(packs), 'ok'); [print(e) for e in errors]"
```

Zero errors or it does not ship. To preview live, copy the pack
into `~/.local/share/agent-aware-terminal/content/`, give an
agent a >7 s task in the app, and watch for
`[content] serving <your-id>` in
`~/.local/share/agent-aware-terminal/decisions.log`.

## Do / Don't

- ✅ Generate packs about the *current* project (its real
  architecture, its real code smells) — that's the best content.
- ✅ Keep ids stable once shipped; progress tracking keys on id.
- ❌ No external URLs/images in packs; scenes are drawn, not fetched.
- ❌ No multi-part questions, no "all of the above".
